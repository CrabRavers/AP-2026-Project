The AI policy (ai-statement.md) makes a missing or false declaration academic misconduct. Check:
1. The AI usage declaration exists in the crate's `main` (`crates/harness/src/main.rs`) and names every module or function the plans say was AI-assisted.
2. For every plan in `.agents/plans/*/` (initial-prompt.md, follow-up-prompts.md, result.md), the functions it says were generated by AI carry, in their doc comment, a statement that they were AI-generated *and* the prompt(s) used.
3. Inversely, flag code that clearly came out of a plan but has no declaration.
4. No change in a plan touched lines authored by another git user (AGENTS.md).

Report per plan directory: OK, or the exact missing declarations with `file:line`. Do not judge whether the AI use itself was allowed; just say whether it is declared.

## Rules
- You are read-only: never edit, write or commit. Your output is a report.
- Each finding: `file:line`, the spec section it violates (e.g. main §5.4), what goes wrong, concretely. No style nits.
- If unsure, say so instead of guessing. If nothing is wrong, say that.
- The spec lives in `docs/spec/` (main.md, protocol.md, org.md, ai-statement.md). If it is missing, tell the user to get the files from the group (see README) and stop.
